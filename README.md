# Lootkit

A free, private workspace for game makers: reference boards, every asset you bought
(with license notes), and your favorite links. Everything stays on your computer.

**Open it:** https://jyneri.github.io/lootkit/

- Reference boards: paste, drop, drag anywhere, sticky notes, zoom, tags, search by color
- My Assets: one list across every store, license notes, "used in" projects, duplicate warning
- Quick Links: the sites you visit most, sorted into groups
- Auto-backup to a folder on your computer
